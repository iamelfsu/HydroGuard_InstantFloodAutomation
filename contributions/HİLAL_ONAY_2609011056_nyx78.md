### Emergency Dispatch & Map Generation

In this section of my project, I built a system to visualize emergency dispatch results and evacuation routes on an interactive map. It is specifically designed to manage logistics and safety statuses for the **ISU Campuses** during potential crisis scenarios (such as a flood event).

#### What it Does
* **Generates an Interactive Emergency Map:** It initializes a map focused on specific geographic coordinates and overlays critical operational data.
* **Visualizes Campus Statuses:** It marks each campus on the map, displaying information about the assigned emergency assets and active safety/route status via customized popups.
* **Draws Evacuation Corridors:** It dynamically draws polyline corridors connecting the assigned emergency response coordinates directly to the respective campuses.
* **Tracks Logistics Bases:** It maps out strategic logistics bases from a registry, marking them as ready for mobilization.
* **Saves the Output:** It automatically compiles all these layers and exports the final product as a standalone HTML map file.

#### Tech Stack & Libraries Used
* **Folium**: Used as the primary library to generate the interactive Leaflet.js maps, markers, polylines, and popups.
* **CARTO Voyager Tiles**: Integrated as the custom, clean basemap background to ensure high scannability of emergency elements.
* **OpenStreetMap Data**: Used as the underlying geographic data source.

#### Breakdown of Core Components

##### 1. Base Map Initialization
I configured the base map (`folium.Map`) using custom `carto_voyager` raster tiles to keep the background clean and professional. The map centers around the core operational area with a default zoom level of 14 and includes a control scale for spatial awareness.

##### 2. `generate_dual_campus_map(dispatch_results: dict)`
This is the main function responsible for plotting the operational dashboard. It handles three primary data loops:
* **Campus Loop:** Iterates through `ISU_CAMPUSES`, reads the `dispatch_results`, places exclamation-sign warning markers on campuses, and links them with a color-coded `PolyLine` representing the evacuation corridor.
* **Logistics Registry Loop:** Iterates through `LOGISTICS_REGISTRY` to drop home-icon markers representing mobilization-ready logistics bases.
* **File Export:** Concludes by executing `.save(OUTPUT_MAP_FILE)` to render the map into a viewable HTML file.
